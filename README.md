# HopeAndBloom

Hope and Bloom Child Development Center website.

## Run locally

Install [Node.js](https://nodejs.org/) if it is not already installed. From the
repository root, run:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

Create a production build with `npm run build`.

The site uses React components, Vite, and the existing CSS stylesheet.
`index.html` is the app entry point; the React app starts in `src/main.jsx`.
Reusable page components are in `src/components/`. The logo and center photos
at the repository root are bundled by Vite.

## Website details

- Headings use Poppins; body text uses Roboto.
- An ABA therapy session costs 1,200.
- The assessment package, including a student handbook and uniform, costs 2,500.
